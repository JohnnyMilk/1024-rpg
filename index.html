PROJECT INDEX

這個入口頁負責說明整個專案的層級。Type 用來區分不同核心玩法；Version 用來區分同一 Type 之下的不同世代設計。每個 Version 都有自己的開發版本與歷程。

PROJECT STRUCTURE
Type = 核心玩法只有主要操作、棋盤規則或戰鬥結構根本改變時，才建立新的 Type。Type 01 的核心是 1024 式上下左右滑動、合併，以及敵我共存在同一棋盤。
Version = 同一 Type 的世代演進Version 代表同一核心玩法的一個主要設計世代。每個 Version 內仍可以從 v0.1 開始試作，直到該 Version 的 v1.0 正式定案。

目前 Type 01 已完成 Version 1；Version 2 已完成 v0.2 的 Skill Pool、戰鬥可讀性與手機 UI 穩定化，下一階段正式進入 v0.3。

FUTURE TYPES
Type 02 and beyond
只有當核心操作不再是 Type 01 的「上下左右滑動＋合併＋敵我共存棋盤」時，才建立新的 Type。單純改成 6×4、改變棋盤形狀或增加 RPG 系統，都仍可以留在 Type 01 的新 Version 裡。
