Version 2 · v0.1

TYPE 01 · DEVELOPMENT BRANCH

起點

Version 2 v0.1 以已定案的 Version 1 v1.0 為基準複製。現階段先保存開發方向，不改變 Version 1 正式版。

v0.1 代表 Version 2 尚在設計與驗證階段；正式規則未定案。

候選進化方向

  • 地圖尺寸：由固定 4×4 延伸到 6×4 等較高棋盤。
  • 不規則地圖：允許缺格、障礙格或特殊形狀，但仍維持上下左右滑動的 Type 01 核心。
  • 英雄數字能力：高階英雄除了 HP，也可能取得額外能力。
  • Skill Build：Boss 後提供技能強化選擇，形成戰士、弓箭手、法師或混合流派。
  • Boss Mechanics：Boss 不只增加 HP/ATK，而是直接影響棋盤與滑動決策。
  • Relics：Boss 戰後取得具有優缺點或流派效果的遺物。
  • Combo / Chain：一次滑動造成多組合併或多技能連鎖時產生額外回饋。
  • Enemy Types：增加少量具有不同棋盤行為的敵人，而非單純增加數值。
  • Meta Progression：待核心 Run 成熟後，再評估局外解鎖與長期成長。

設計原則

Version 2 的新增系統應盡量服務 Type 01 最重要的決策：玩家下一步要往哪個方向滑。若核心仍是滑動、合併與敵我共存棋盤，就仍屬 Type 01。
