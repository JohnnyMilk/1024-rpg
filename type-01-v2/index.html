目前核心規則

01 · 新最高數字 = Level Up只有首次突破本局歷史最高英雄數字才會觸發技能三選一。
02 · 全局 Skill Poolv0.2 的技能不分職業、不綁定單一英雄；v0.3 正在重新整理一般技能池與職業專屬技能池。
03 · 固定動畫序列移動 → 合併 → 攻擊與 HP 跳字同步 → 死亡。若死亡觸發新的效果，必須等該死亡動畫完成後再進入下一階段，形成 Death Wave 連鎖。
04 · 戰鬥資訊視覺化一般暗影刺客固定 1 HP，因此不再浪費格內空間顯示 HP；英雄與 Boss 使用血量條呈現目前生命比例。
05 · 手機優先資訊介面上方統計卡可點擊查看 Game Info；說明以覆蓋遊戲畫面的置頂浮動視窗呈現。
06 · 移除 Version 1 固定三技能Version 2 不再提供每次合併戰士、每 3 次弓箭手、每 5 次法師的固定技能。

下一階段：v0.3

v0.2 作為穩定基線v0.3 將從目前已穩定的 v0.2 分出新的可玩版本；不覆寫 v0.2。
一般技能 + 職業技能v0.3 將把成長拆成一般技能池與職業專屬技能池；首發職業方向為近戰、遠程、輔助。詳細技能仍在逐項確認。
場外技能升級 · Meta Progression所有技能除了單局內取得之外，未來都可在遊戲回合之外再次成長。每個技能具有基礎狀態 + 3 次場外升級，形成類 Roguelike／Survivor 的跨局成長。升級所需資源與取得方式目前尚未決定。
幸運 · 升級範例目前基礎效果為 25% 機率提升生成英雄一階；場外 Upgrade 1 / 2 / 3 可依序提升為 50% / 75% / 100%。其他技能也採 Base + 3 upgrades，但每級實際強化內容可依技能個別設計。
