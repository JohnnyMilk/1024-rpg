VERSION 2 · v0.1 · PLAYABLE PROTOTYPE

Skill Pool Prototype

第一次合出新的歷史最高英雄數字（2、4、8、16…）時，暫停遊戲並從技能池隨機提供三個未取得技能，玩家三選一。取得的技能為本局全局共享能力，並以圖示列顯示；點擊圖示可查看效果。

v0.1 已定案的核心改動

01 · 新最高數字 = Level Up只有首次突破本局歷史最高英雄數字才觸發技能選擇；再次合出已達成的數字不會重複取得技能。
02 · Skill Pool 三選一每次突破後隨機提供 3 個未取得技能。技能不分戰士、弓箭手、法師，也不綁定單一英雄。
03 · 全局共享技能技能可以由移動、合併、受傷、英雄死亡、敵人死亡、Boss、生成、棋盤狀態或 Score 等事件觸發。
04 · 技能圖示列每取得一個技能就增加一個圖示；玩家可點擊圖示查看技能名稱與完整效果。
05 · 移除 Version 1 固定三技能Version 2 不再提供「每次合併的戰士」、「每 3 次合併的弓箭手」、「每 5 次合併的法師」固定技能。

後續候選工作

Map System4×4 延伸至 6×4 與不規則棋盤。
Boss Mechanics讓 Boss 改變棋盤與滑動決策，而不只是 HP／ATK 成長。
Enemy Types / Relics / Combo待 Skill Pool 基礎驗證後逐步加入，並持續以「下一步往哪滑？」為設計核心。

Version 2 開發歷程

v0.1第一個可玩原型。以新最高英雄數字作為技能成長節點；每次突破技能池三選一，全局共享並加入可點擊的技能圖示列；移除 Version 1 的戰士／弓箭手／法師固定 1／3／5 合併技能。
