目前核心規則

01 · 新最高數字 = Level Up只有首次突破本局歷史最高英雄數字才會觸發技能三選一。
02 · 全局 Skill Pool技能不分職業、不綁定單一英雄，可以由移動、合併、受傷、死亡、Boss、生成、棋盤狀態等事件觸發。
03 · 固定動畫序列移動 → 合併 → 攻擊與 HP 跳字同步 → 死亡。若死亡觸發新的攻擊，必須等該死亡動畫完成後再進入下一個攻擊／扣血階段，形成 Death Wave 連鎖。
04 · 移除 Version 1 固定三技能Version 2 不再提供每次合併戰士、每 3 次弓箭手、每 5 次法師的固定技能。

Map System4×4 延伸至 6×4 與不規則棋盤。

Enemy Types / Relics / Combo待 Skill Pool 基礎驗證後逐步加入。
