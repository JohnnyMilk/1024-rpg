● v0.1 PLANNING

Version 2 的定位

不重做 Type 01，而是在保留「上下左右滑動、英雄合併、敵我共存在棋盤」這個核心的前提下，增加更多地圖變化、Build 選擇與 Boss／敵人帶來的棋盤決策。

設計原則：新增的系統應該盡量回到同一個核心問題——「下一步要往哪個方向滑？」如果一個系統完全不影響這個判斷，就要非常謹慎地加入。

目前候選開發方向

01 · 地圖尺寸變化從固定 4×4 延伸到 6×4 等較高棋盤，測試更長的移動距離、更多單位容量與不同的壓力節奏。
02 · 不規則地圖加入缺格、障礙格或特殊地圖形狀。只要核心仍然是四方向滑動與合併，就仍屬 Type 01。
03 · 英雄數字能力高階英雄除了 HP 增加之外，也可能在特定數字取得護盾、傷害、額外技能或其他能力，讓「是否繼續合併」成為更重要的策略選擇。
04 · Skill BuildBoss 戰後提供技能強化選擇，使戰士、弓箭手、法師形成不同流派，也允許混合 Build。
05 · Boss MechanicsBoss 不再只是 HP／ATK 變高，而是能鎖格、召喚、標記區域、改變滑動限制或以其他方式直接影響棋盤。
06 · Relics加入具有明確效果與取捨的遺物，例如提高分數、改變技能、增加風險或強化特定流派。
07 · Combo / Chain一次滑動造成多組合併、或同回合觸發多個技能時，提供連鎖與分數回饋，鼓勵玩家預先布置棋盤。
08 · Enemy Types增加少量但行為差異明確的敵人，例如遠程、護盾、穿越或召喚型；重點是改變滑動策略，而不是只增加數值。
09 · Meta Progression等單局 Run 的玩法足夠成熟後，再評估局外解鎖、長期成長或挑戰模式，不急著在早期加入。

Version 2 開發歷程

v0.1建立 Version 2 設計頁。以 Version 1 v1.0 為基準，先記錄地圖尺寸、不規則棋盤、英雄能力、Skill Build、Boss Mechanics、Relics、Combo、Enemy Types 與 Meta Progression 等候選方向；尚未定案實裝順序。
