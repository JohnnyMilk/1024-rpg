# 1024 RPG — Type 02 Design Notes

## Status
**VERSION 1 · v0.1 INTEGRATED POC**

The previous City / Management direction (old v0.1–v0.3) is abandoned and archived. Type 02 is now a **three-board 1024 Roguelite**: 王國遠征、鍊金工坊、地下城探索都使用上下左右滑動與合併，但每個系統賦予 1024 不同意義。

> **1024 王國遠征 → 素材 → 1024 鍊金 → 回復藥 → 1024 地下城 → 素材 → 回城 → 再出發。**

---

# V0.1 POC — playable scope

V0.1 的目的不是完成完整遊戲，而是第一次把三種 1024 玩法串成一個可玩的循環。所有數值、配方、敵人與掉落都是 POC 暫定值。

## Town / 城鎮
城鎮是所有玩法的中央 Hub。V0.1 提供三個主要功能入口（其中「遠征」就是目前取得一般/Boss素材的主要方式）：

1. **⚔️ 王國遠征 / 找素材** — 派兵出征，打小怪取得一般素材，擊敗第一隻 Boss 取得 Boss 素材。
2. **🧪 鍊金工坊** — 使用兩種素材在 1024 棋盤製作回復藥。
3. **🏰 地下城探索** — 進入可持續深入的 1024 Roguelike 地下城。

城鎮顯示玩家目前持有的一般素材、Boss 素材、回復藥與最佳地下城深度。

---

## Material system — V0.1 only
只保留兩種材料，避免 POC 過早複雜化：

- **🦴 一般素材（Monster Material）**：擊敗普通怪物掉落。
- **🔮 Boss 核心（Boss Core）**：擊敗王國遠征第一隻 Boss 掉落。

V0.1 唯一鍊金成品：
- **🧪 回復藥（Healing Potion）**。

暫定基本配方概念：一般素材與 Boss 核心都必須參與，透過鍊金 1024 棋盤完成反應後產生回復藥。具體數量與合併節奏由 POC 實玩再調整。

# 1. 王國遠征 — Expedition POC

## Screen structure
**上半部：2D 橫向自動戰鬥。**
隊伍由左往右前進，依序遇到普通怪，最後遇到第一隻 Boss。

**下半部：4×4 1024 單位棋盤。**
玩家上下左右滑動，相同數字合併。合併會直接補充 / 強化上方遠征隊的戰力。

## V0.1 run rule
- 遠征開始時玩家有固定 HP。
- 上方敵人會持續與隊伍交戰。
- 普通怪死亡：+1 🦴一般素材。
- 擊敗數隻普通怪後出現第一隻 Boss。
- Boss 死亡：+1 🔮Boss 核心，**本次遠征立即成功結束並回城。**
- 玩家 HP 歸零：**遠征失敗並回城。**
- 已取得的一般素材在 POC 中保留；Boss 核心只有真正擊敗 Boss 才取得。

V0.1 不做第二隻 Boss、不做完整世界地圖、不做多區域選擇。

## POC question
> 下方 swipe / merge → 上方戰力改變 → 打怪 → 掉素材，這個循環是否有即時回饋與持續操作慾望？

# 2. 鍊金工坊 — Alchemy POC

鍊金工坊本身是一張 **4×4 1024 棋盤**，不是傳統 Craft 按鈕。

## V0.1 rules
- 玩家從庫存投入 🦴一般素材與 🔮Boss 核心。
- 材料以 Tile 進入棋盤。
- 上下左右滑動整理材料。
- 相同素材可合併升階。
- 當一般素材與 Boss 核心達到 V0.1 配方反應條件時，產生 **🧪回復藥**。
- 完成的回復藥加入城鎮庫存，可帶進地下城使用。

V0.1 暫定最簡單可測配方：
> **2 × 🦴一般素材 + 1 × 🔮Boss 核心 → 1 × 🧪回復藥**

實作時仍透過 1024 棋盤操作完成，而不是直接點擊「製作」。此比例是測試值，後續依實玩調整。

## POC question
> 只有兩種材料時，透過 swipe 整理、合併與觸發配方，是否已經比傳統 Craft 選單有趣？

---

# 3. 地下城探索 — Dungeon POC

地下城是 **1024 Roguelike 棋盤**。棋盤本身就是探索空間。

## Core rule
- 玩家以 swipe 改變棋盤局勢。
- 一次有效滑動 = 一個探索 Turn。
- 棋盤可出現玩家、敵人、素材與下一層入口。
- 接觸敵人觸發傷害 / 戰鬥。
- 擊敗地下城普通怪可取得 🦴一般素材。
- 深層可逐步提高敵人強度。
- 玩家可使用 🧪回復藥恢復 HP。

## Infinite descent
地下城在設計上**沒有固定最終層**。

每完成一層後生成下一層，深度持續增加。Run 只在兩種情況停止：
1. **玩家主動「回城」**：保留目前取得的戰利品並返回 Town。
2. **玩家死亡**：地下城 run 結束並返回 Town。

V0.1 不需要製作大量房型，只需要能證明「進下一層 → 變難 → 想繼續還是回城」的風險 / 報酬循環。

### V0.1 death rule
POC 暫定：地下城死亡時，本次地下城內新取得的素材失去；進地下城前原本城鎮庫存不受影響。主動回城則可帶回本次取得的素材。

## POC question
> 玩家是否會因為已取得的戰利品與剩餘 HP，在「再下一層」和「現在回城」之間產生真正的猶豫？

# V0.1 complete loop

**🏘️ TOWN**
→ ⚔️ 王國遠征 / 找素材
→ 4×4 1024 生產戰力 + 上方 2D 自動戰鬥
→ 小怪掉 🦴
→ 第一隻 Boss 掉 🔮
→ 回城
→ 🧪 鍊金工坊
→ 4×4 1024 材料合併
→ 🧪 回復藥
→ 回城
→ 🏰 地下城
→ 1024 Roguelike 無限深入
→ 使用回復藥 / 收集素材
→ 主動回城帶回戰利品，或死亡結束探索
→ TOWN

---

# V0.1 deliberately excluded
為了保持 POC 可驗證性，以下暫時不做：
- 多個王國區域；
- 第二隻以上的遠征 Boss；
- 大量兵種 / 職業；
- 超過兩種素材；
- 回復藥以外的鍊金道具；
- 複雜鍊金配方圖鑑；
- 地下城商人、祭壇、陷阱、鑰匙與複雜地形；
- 完整永久 Meta progression；
- 正式美術與複雜動畫。

# Three-board identity
| 系統 | 1024 棋盤代表 | 合併 / 滑動的意義 | V0.1 主要回饋 |
| --- | --- | --- | --- |
| 王國遠征 | 軍隊生產 | 合併戰力 | 上方隊伍打怪、掉素材 |
| 鍊金工坊 | 鍊金桌 | 素材升階 / 配方反應 | 製作回復藥 |
| 地下城 | 探索空間 | 移動、戰鬥、深入 | 深度、HP、戰利品、撤退 |

# Design principles
1. 玩家只需要熟悉上下左右 swipe，但三種棋盤必須產生不同決策。
2. 1024 合併必須產生遊戲後果，不只是分數。
3. 王國遠征下方棋盤與上方 2D 戰鬥是一個系統。
4. 鍊金必須透過 1024 棋盤完成，不使用傳統一鍵 Craft 取代核心玩法。
5. 地下城必須透過 1024 swipe 探索，並提供無限深入 / 主動撤退的 Roguelike 壓力。
6. 回復藥把「遠征取得素材 → 鍊金 → 地下城生存」三者第一次串起來。
7. V0.1 優先驗證好不好玩，不追求內容量。
