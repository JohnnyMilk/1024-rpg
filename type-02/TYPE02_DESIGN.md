# 1024 RPG — Type 02 Design Notes

## Status
**VERSION 1 · v0.1 INTEGRATED POC**

The previous City / Management direction (old v0.1–v0.3) is abandoned and archived. Type 02 is now a **three-board 1024 Roguelite**: 王國遠征、鍊金工坊、地下城探索都使用上下左右滑動與合併，但每個系統賦予 1024 不同意義。

> **1024 王國遠征 → 素材 → 1024 鍊金 → 回復藥 → 1024 地下城 → 素材 → 回城 → 再出發。**

---

# V0.1 POC — playable scope
V0.1 的目的不是完成完整遊戲，而是第一次把三種 1024 玩法串成一個可玩的循環。所有數值、配方、敵人與掉落都是 POC 暫定值。

## Town / 城鎮
城鎮是中央 Hub：⚔️ 王國遠征、🧪 鍊金工坊、🏰 地下城探索。城鎮庫存顯示 🦴一般素材、🔮Boss 核心、🧪回復藥與最佳地下城深度。

## Material system — V0.1 only
- **🦴 一般素材**：遠征普通敵人 / 地下城素材。
- **🔮 Boss 核心**：遠征 Boss 戰利品。
- V0.1 唯一鍊金成品：**🧪 回復藥**。

# 1. 王國遠征 — Expedition POC

## Core thesis
王國遠征的主要壓力是：**玩家在下方 1024 的合併 / 生兵速度，能否追上敵方持續自動產兵與前線推進速度。**

上半部是 2D 橫向自動戰場；下半部是 4×4 1024 單位鍛造盤。玩家不是直接攻擊，而是透過 Merge 持續補充遠征軍。

## Captain / 敗北條件
- 我方最左側固定存在一名 **隊長**，有獨立 HP 與血條。
- 隊長是遠征 Run 的核心生命線。
- 敵軍突破前線後會向左推進並攻擊隊長。
- **隊長 HP 歸零 = 本次遠征立即失敗。**
- 遠征失敗時，本次 Run 尚未安全帶回城的所有 🦴 / 🔮 戰利品全部失去；原本城鎮庫存不受影響。

## Merge → Unit / Durability rule
- 每發生 1 組真正 Merge，產生 1 名新士兵。
- 同一次 Swipe 若完成多組 Merge，每組都各自產生一名士兵。
- **合併次數 = 兵量。**
- **合併後的數字 = 該士兵可承受的「標準攻擊次數」。** 例如 `1+1→2` 產生的 Lv.2 單位，在第一關基準敵軍每次造成 1 點傷害時，大約被打 2 下死亡；Lv.4 約可承受 4 下，以此類推。
- 後續關卡敵人單次傷害提高，因此同一個 Lv.2 士兵在後段會更快死亡，迫使玩家合出更高數字。
- 士兵從左側加入並自動向右前進。

## Enemy pressure
- 敵軍不是「上一隻死亡後才出下一隻」，而是依各關卡的生成間隔**持續增援**，因此戰場可同時存在多名敵人。
- 第 1 關已提高為約每秒一波增援；第 2、3 關生成速度進一步提高。
- 小兵數量、HP、攻擊力、Boss 強度都隨關卡提高。
- 第 1 關標準小怪攻擊約為 1，作為「Lv.2 我方單位約兩下死亡」的耐久基準。

## Unit variety / targeting
V0.1 驗證三種基本戰鬥角色，敵我雙方都可使用：
- **近戰**：前線接敵、短距離攻擊，帶明顯近身揮擊 / 突進動畫。
- **弓箭手**：遠距離攻擊，射出可見箭矢；敵方弓手可優先打較後方單位。
- **法師**：更遠距離攻擊，射出可見魔法彈；可選擇敵陣中段等不同位置。

因此遠程敵人不必永遠攻擊最前線，我方陣形中的中段 / 後排也會承受壓力。

## Visible combat feedback
- 隊長、我方士兵、敵方小兵、Boss 全部有獨立 HP 與頭頂血條。
- 近戰有揮擊 / 突進動畫；弓箭手有箭矢飛行動畫；法師有施法與魔法彈飛行動畫。
- 受到攻擊後血條下降並播放受擊回饋；HP 歸零播放死亡動畫。
- 下方 1024 棋盤新增 Tile 出現動畫，以及 Merge 後的放大 / 回彈 / 亮度動畫，讓生兵操作有更直接的正向回饋。

## Stage scenery / 關卡轉場
- 三關維持不同背景色調。
- POC 不使用正式場景美術，而是在背景以大量低對比灰色主題文字（如 TREE / PINE / FERN、ROCK / DUNE、ICE / SNOW / TOWER）重複鋪陳，並持續做緩慢放大縮小動畫，形成森林、峽谷、冰霜要塞的抽象景深。
- **進入下一關時，上方戰場必須完全清空**：上一關存活士兵與敵人不帶入；重新放置隊長並從空戰場開始。
- 下方 1024 棋盤目前保留，讓玩家前一關累積的棋盤進度仍有策略價值。

## Three-stage V0.1 expedition
1. **翠影林道** — 森林主題；7 名基準敵軍後出現森牙王；敵軍約每 1 秒持續增援。
2. **赤砂峽谷** — 赤砂 / 火山主題；9 名更強敵軍後出現赤角戰鬼；生成速度提高。
3. **霜月要塞** — 冰霜要塞主題；11 名高強度敵軍後出現霜月龍王；遠程 / 法術與生成速度壓力最高。

## Boss checkpoint / Risk–Reward
- 每擊敗一名 Boss：本次 Run 暫存 **+1 🔮 Boss 核心**。
- Boss 擊敗後暫停並詢問：**帶戰利品回城 / 繼續下一關**。
- 選擇回城：本次遠征累積的所有 🦴 / 🔮 正式加入城鎮庫存。
- 選擇繼續：保留本次 Run 暫存戰利品與下方 1024 棋盤，**清空上方戰場**後進入下一關；若之後隊長死亡，尚未帶回城的戰利品全部失去。
- 第三名 Boss 擊敗後完成三關 POC並可安全帶回戰利品。
- 主動放棄遠征同樣不會帶回尚未結算的戰利品。

## POC question
> 敵軍持續增援後，玩家是否真的感受到「合成速度必須追過敵方生兵速度」？以合併數字直接代表士兵耐久後，玩家是否會自然理解高階 Merge 的價值？攻擊、投射物、場景與棋盤動畫是否提供足夠清楚且正向的即時回饋？

# 2. 鍊金工坊 — Alchemy POC
鍊金工坊本身是一張 **4×4 1024 棋盤**，不是傳統 Craft 按鈕。

## V0.1 rules
- 玩家從城鎮庫存投入 🦴 與 🔮。
- 材料以 Tile 進入棋盤，透過上下左右 Swipe 整理與合併。
- 相同一般素材可合併升階。
- V0.1 測試配方：**2 × 🦴 + 1 × 🔮 → 1 × 🧪回復藥**。
- 製作必須透過 1024 棋盤完成，不改成一鍵 Craft。

## POC question
> 只有兩種材料時，透過 swipe 整理、合併與觸發配方，是否已經比傳統 Craft 選單有趣？

# 3. 地下城探索 — Dungeon POC
地下城是 **1024 Roguelike 棋盤**，棋盤本身就是探索空間。

## Core rule
- 玩家以 Swipe 改變棋盤局勢；一次有效滑動 = 一個探索 Turn。
- 棋盤可出現玩家、敵人、素材與下一層入口。
- 接觸敵人觸發戰鬥，接觸素材取得 🦴，接觸 ⬇️ 進入下一層。
- 深層逐步提高敵人強度。
- 玩家可使用 🧪 回復藥；V0.1 暫定 +5 HP。

## Infinite descent / death rule
地下城沒有固定最終層。玩家可主動回城安全帶回本次戰利品；死亡則失去本次地下城新取得素材，進地下城前的城鎮庫存不受影響。

# V0.1 complete loop
**🏘️ TOWN** → ⚔️ 王國遠征 → 1024 Merge 生兵 / 守護隊長 / 三關橫向自動戰鬥 → Boss checkpoint 決定回城或冒險繼續 → 安全回城才把 🦴 / 🔮 加入庫存 → 🧪 1024 鍊金 → 🧪 回復藥 → 🏰 1024 地下城 → 深入 / 使用藥水 / 收集素材 → 主動回城或死亡 → TOWN

| 系統 | 1024 棋盤代表 | 合併 / 滑動的意義 | V0.1 主要回饋 |

| 王國遠征 | 軍隊生產 | 每組 Merge 生兵；合併數字直接決定耐久 | 生兵速度 vs 敵軍速度、隊長生存、Boss checkpoint |

# Design principles
1. 玩家只需要熟悉上下左右 Swipe，但三種棋盤必須產生不同決策。
2. 1024 合併必須產生遊戲後果，不只是分數。
3. 王國遠征以「玩家 Merge / 生兵速度 vs 敵軍持續生成速度」作為核心壓力。
4. 合併數字直接對應士兵基礎耐久，使高階數字的價值直觀可讀。
5. 遠征戰利品採 Run 暫存制；安全回城才正式入庫。
6. 鍊金必須透過 1024 棋盤完成。
7. 地下城必須透過 1024 Swipe 探索，並提供深入 / 撤退壓力。
8. V0.1 優先驗證好不好玩；動畫用於強化操作與戰鬥回饋，不代表正式美術規格。
