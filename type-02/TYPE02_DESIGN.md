# 1024 RPG — Type 02 Design Notes

## Status
**VERSION 1 · DUNGEON-FIRST REDESIGN / PRE-POC**

Type 02 正式停止「王國遠征」方向。舊遠征實作保留在既有 V0.1 作為歷史 POC，不再繼續擴充；City / Management 方向同樣維持封存。

Type 02 接下來只專注一個主要遊戲：

> **1024 地下城 Roguelike：棋盤本身就是地下城，每一次 Swipe 同時改變移動、敵人、戰鬥、素材與風險。**

城鎮與鍊金保留，但降為地下城的支援系統，不再與地下城並列為三套主玩法。

---

# 1. 核心循環

**🏘️ 城鎮**
→ 整備 / 鍊金 / 永久紀錄
→ **🏚️ 1024 地下城**
→ 探索 / 戰鬥 / 合併 / 取得素材
→ 選擇繼續深入或安全撤退
→ 安全撤退：戰利品入庫
→ 死亡：失去本輪尚未帶回的戰利品
→ 回城再出發

核心 Risk–Reward 不再由遠征 Boss checkpoint 承擔，而直接存在於地下城的「繼續深入 / 現在撤退」決策。

---

# 2. Dungeon-first 核心規則

## 棋盤就是地下城
- 使用 4×4 棋盤。
- 玩家仍只需要上下左右 Swipe。
- **一次有效 Swipe = 一個 Turn。**
- Swipe 不只是角色走一步，而會讓棋盤上的可移動物件一起依規則改變位置。
- 每個 Turn 都可能同時改變玩家位置、怪物距離、合併機會、掉落位置與逃生路線。

## Player
- 🧙 玩家有 HP、攻擊力與可成長能力。
- 玩家死亡時，本輪尚未安全帶回城的戰利品全部失去。
- 城鎮既有資產與永久進度不受影響。

## Enemy archetypes
將原遠征已驗證的戰鬥角色轉入地下城：

- 👺 **近戰怪物**：主動逼近玩家，接觸後近戰攻擊。
- 🏹 **弓箭手**：保持距離，在符合射線 / 距離條件時遠程攻擊。
- 🔮 **法師**：遠程魔法與特殊效果，後續可加入地形、詛咒、召喚等能力。
- 👑 **Boss**：固定深度出現，具有獨立規則，而不是單純高 HP 怪物。

---

# 3. 1024 必須直接影響地下城

這是新版 Type 02 最重要的設計原則。

## Numbered enemies
敵人可帶數值，例如：

**👺2 / 👺4 / 👺8 / 👺16**

數字代表敵人的階級 / 強度，而不是單純 UI 標籤。

## Enemy merge
- 兩個符合條件的同類、同數值敵人在 Swipe 後碰在一起，可以合併成更高階敵人。
- 例：**👺4 + 👺4 → 👺8**。
- 因此玩家不能只思考「我要往哪裡走」，還必須預判 Swipe 是否會讓怪物變強。
- 高階敵人應同時提高風險與報酬，避免合併永遠只有懲罰。

## Materials / objects
素材、寶箱與其他棋盤物件也可以逐步加入數值與合併規則，使 1024 不只存在於敵人身上。

第一個 POC 不需要一次實裝所有物件；優先驗證「敵人會因 Swipe 合併」是否能產生真正的 1024 決策。

---

# 4. Dungeon structure

地下城沒有固定最終層，以深度作為 Run 進程。

建議第一版節奏：

- 一般樓層：探索、怪物、素材。
- 特殊樓層：寶箱 / 事件 / 商人等，後續逐步加入。
- **每 5 層 Boss 戰**，作為明確節奏點。
- Boss 擊敗後玩家仍可選擇繼續深入或安全撤退。

越深：
- 初始怪物數增加。
- 怪物數值提高。
- 遠程 / 法師比例提高。
- 特殊規則逐步出現。
- 高階素材與獎勵機會提高。

---

# 5. Loot / Retreat

地下城採 Run 暫存制。

- 🦴 一般素材：普通怪物 / 探索取得。
- 🔮 Boss 核心：Boss 或特殊高階目標取得。
- 其他素材未來再擴充。
- Run 中取得的資源先放在暫存戰利品。
- **主動撤退回城後才正式入庫。**
- 死亡則失去本輪暫存戰利品。

撤退不是失敗，而是核心策略。

---

# 6. Alchemy — support system

鍊金工坊保留，但不再作為與地下城同等規模的第二主遊戲。

目前定位：
- 使用地下城帶回的素材。
- 製作 🧪 回復藥與未來地下城消耗品。
- 仍可保留 1024 Swipe / Merge 的鍊金表現，但是否值得保留完整 4×4 獨立棋盤，等地下城核心完成後再評估。
- 第一優先永遠是地下城玩法深度，不因鍊金拖慢核心驗證。

---

# 7. Town — support hub

城鎮只承擔：
- Run 前整備。
- 素材與道具庫存。
- 鍊金。
- 最深樓層 / Boss / 成就等永久紀錄。
- 未來可能的永久成長。

城鎮不是另一套 1024 主玩法。

---

# 8. First new Dungeon POC

下一個可玩版本先驗證最小但完整的地下城核心：

1. 4×4 地下城。
2. 玩家 HP。
3. 👺2 / 👺4 等數值近戰怪。
4. Swipe = Turn。
5. 相同怪物可以因 Swipe 合併升階。
6. 玩家與怪物接觸會戰鬥。
7. 🦴 戰利品。
8. ⬇️ 下一層。
9. 主動撤退安全帶回戰利品。
10. 死亡失去本輪戰利品。
11. 深度提高怪物初始強度。
12. 每 5 層加入 Boss 節奏。

第一輪先不追求大量職業、事件、裝備或華麗 UI；先回答最重要的問題：

> **當 Swipe 同時代表移動與「可能把敵人合成得更強」時，玩家是否會開始像玩 1024 一樣規劃地下城？**

如果答案是肯定的，再依序加入弓箭手、法師、寶箱、事件、裝備、特殊 Tile、Boss 機制與更完整的鍊金。

# Design principles

1. **地下城是唯一主要玩法。**
2. 棋盤本身就是世界，不另開一個獨立戰鬥畫面。
3. Swipe 必須同時造成空間與戰術後果。
4. 1024 Merge 必須真正改變敵人 / 素材 / 局勢，而不是只增加分數。
5. 深入與撤退必須形成持續 Risk–Reward。
6. 敵人種類增加時，要改變玩家的 Swipe 決策，而不是只有不同數值。
7. Boss 必須有棋盤規則，不只是高 HP。
8. 城鎮與鍊金服務地下城，不與地下城爭奪開發重心。
9. 先驗證最小核心，再增加內容量與美術。
10. 舊 POC 保留作為設計歷史，不回頭覆寫。
