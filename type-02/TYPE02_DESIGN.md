# 1024 RPG — Type 02 Design Notes

## Status
**VERSION 1 · v0.1 INTEGRATED POC**

The previous City / Management direction (old v0.1–v0.3) is abandoned and archived. Type 02 is now a **three-board 1024 Roguelite**: 王國遠征、鍊金工坊、地下城探索都使用上下左右滑動與合併，但每個系統賦予 1024 不同意義。

> **1024 王國遠征 → 素材 → 1024 鍊金 → 回復藥 → 1024 地下城 → 素材 → 回城 → 再出發。**

---

# V0.1 POC — playable scope
V0.1 的目的不是完成完整遊戲，而是第一次把三種 1024 玩法串成一個可玩的循環。所有數值、配方、敵人與掉落都是 POC 暫定值。

## Town / 城鎮
城鎮是所有玩法的中央 Hub。V0.1 提供三個主要功能入口：
1. **⚔️ 王國遠征 / 找素材** — 透過 1024 合併持續派出士兵，打小怪取得一般素材，擊敗第一隻 Boss 取得 Boss 核心。
2. **🧪 鍊金工坊** — 使用兩種素材在 1024 棋盤製作回復藥。
3. **🏰 地下城探索** — 進入可持續深入的 1024 Roguelike 地下城。

城鎮顯示玩家目前持有的一般素材、Boss 核心、回復藥與最佳地下城深度。

---

## Material system — V0.1 only
只保留兩種材料：
- **🦴 一般素材（Monster Material）**：擊敗普通怪物掉落。
- **🔮 Boss 核心（Boss Core）**：擊敗王國遠征第一隻 Boss 掉落。

V0.1 唯一鍊金成品：**🧪 回復藥（Healing Potion）**。

# 1. 王國遠征 — Expedition POC

## Screen structure
**上半部：2D 橫向自動遠征戰場。**

我方士兵從畫面左側出生並自動向右前進。怪物 / Boss 從最右側出現並向左接近。雙方在途中碰撞後停止移動、自動互相攻擊；一方死亡後，存活者繼續向原方向前進。

**下半部：4×4 1024 單位鍛造棋盤。**

玩家上下左右 Swipe。棋盤移動本身不直接造成上方傷害；真正的「合併」才是生產軍隊的行為。

### Merge → Unit 規則
- 每發生 **1 組真正的合併**，上方就產生 **1 名新的士兵**。
- 士兵強度由該組合併完成後的數字決定。
- 例如 `1 + 1 → 2` 會產生 Lv.2 士兵；`2 + 2 → 4` 會產生 Lv.4 士兵。
- 同一次 Swipe 若同時完成多組合併，每一組都分別產生士兵。例如一次完成 3 組 Merge，就會派出 3 名士兵。
- 因此玩家的 **合併次數決定兵量；合併階級決定兵質**。
- 上方不是單一角色或共用 Power 數值，而是可以同時存在多名獨立士兵；持續合併會形成前線戰鬥與後續援軍持續向右推進的遠征感。

## Visible combat feedback
- 每一名我方士兵都有自己的 HP 與頭頂血條。
- 每一隻普通怪與 Boss 也都有自己的 HP 與頭頂血條。
- 敵我碰撞後才進入戰鬥。
- 攻擊必須有簡單可見的攻擊動作 / 位移回饋。
- 受到攻擊後，血條可見地扣減。
- HP 歸零後播放簡單死亡動畫，再從戰場移除。
- 戰鬥結束後，存活單位繼續前進。

## V0.1 run rule
- 普通怪死亡：+1 🦴一般素材。
- 擊敗數隻普通怪後，第一隻 Boss 從右側出現。
- Boss 死亡：+1 🔮Boss 核心，**本次遠征立即成功結束並回城。**
- 已取得的一般素材在 POC 中保留；Boss 核心只有真正擊敗 Boss 才取得。
- V0.1 不做第二隻 Boss、不做完整世界地圖、不做多區域選擇。

## POC question
> 下方持續 Merge → 不斷生產不同強度的士兵 → 士兵實際向右遠征、形成隊伍與前線 → 遇敵自動戰鬥 → 掉素材，是否會產生「我正在組建並推進一支軍隊」的即時回饋與持續操作慾望？

# 2. 鍊金工坊 — Alchemy POC
鍊金工坊本身是一張 **4×4 1024 棋盤**，不是傳統 Craft 按鈕。

## V0.1 rules
- 玩家從庫存投入 🦴一般素材與 🔮Boss 核心。
- 材料以 Tile 進入棋盤。
- 上下左右滑動整理材料。
- 相同素材可合併升階。
- 當一般素材與 Boss 核心達到 V0.1 配方反應條件時，產生 **🧪回復藥**。
- 完成的回復藥加入城鎮庫存，可帶進地下城使用。

V0.1 暫定最簡單可測配方：
> **2 × 🦴一般素材 + 1 × 🔮Boss 核心 → 1 × 🧪回復藥**

實作時仍透過 1024 棋盤操作完成，而不是直接點擊「製作」。此比例是測試值，後續依實玩調整。

## POC question
> 只有兩種材料時，透過 swipe 整理、合併與觸發配方，是否已經比傳統 Craft 選單有趣？

---

# 3. 地下城探索 — Dungeon POC
地下城是 **1024 Roguelike 棋盤**。棋盤本身就是探索空間。

## Core rule
- 玩家以 swipe 改變棋盤局勢。
- 一次有效滑動 = 一個探索 Turn。
- 棋盤可出現玩家、敵人、素材與下一層入口。
- 接觸敵人觸發傷害 / 戰鬥。
- 擊敗地下城普通怪可取得 🦴一般素材。
- 深層可逐步提高敵人強度。
- 玩家可使用 🧪回復藥恢復 HP；V0.1 暫定 +5 HP。

## Infinite descent
地下城在設計上**沒有固定最終層**。每完成一層後生成下一層，深度持續增加。

Run 只在兩種情況停止：
1. **玩家主動「回城」**：保留目前取得的戰利品並返回 Town。
2. **玩家死亡**：地下城 run 結束，本次地下城內新取得的素材失去；進地下城前原本城鎮庫存不受影響。

## POC question
> 玩家是否會因為已取得的戰利品與剩餘 HP，在「再下一層」和「現在回城」之間產生真正的猶豫？

→ 4×4 1024 Merge 持續派出士兵 + 上方 2D 橫向自動遠征
→ 小怪掉 🦴
→ 第一隻 Boss 掉 🔮
→ 回城

→ 4×4 1024 材料合併
→ 🧪 回復藥
→ 回城
→ 🏰 地下城
→ 1024 Roguelike 無限深入
→ 使用回復藥 / 收集素材
→ 主動回城帶回戰利品，或死亡結束探索

# V0.1 deliberately excluded
為了保持 POC 可驗證性，以下暫時不做：
- 多個王國區域；
- 第二隻以上的遠征 Boss；
- 大量兵種 / 職業；
- 超過兩種素材；
- 回復藥以外的鍊金道具；
- 複雜鍊金配方圖鑑；
- 地下城商人、祭壇、陷阱、鑰匙與複雜地形；
- 完整永久 Meta progression；
- 正式美術與複雜動畫。

# Three-board identity
| 系統 | 1024 棋盤代表 | 合併 / 滑動的意義 | V0.1 主要回饋 |
| --- | --- | --- | --- |
| 王國遠征 | 軍隊生產 | 每組 Merge 產生一名對應階級的新士兵 | 兵量、兵質、前線推進、打怪掉素材 |
| 鍊金工坊 | 鍊金桌 | 素材升階 / 配方反應 | 製作回復藥 |
| 地下城 | 探索空間 | 移動、戰鬥、深入 | 深度、HP、戰利品、撤退 |

---

# Design principles
1. 玩家只需要熟悉上下左右 swipe，但三種棋盤必須產生不同決策。
2. 1024 合併必須產生遊戲後果，不只是分數。
3. 王國遠征下方棋盤與上方 2D 戰鬥是一個系統；Merge 必須實際生產可見、獨立存在的遠征士兵。
4. 鍊金必須透過 1024 棋盤完成，不使用傳統一鍵 Craft 取代核心玩法。
5. 地下城必須透過 1024 swipe 探索，並提供無限深入 / 主動撤退的 Roguelike 壓力。
6. 回復藥把「遠征取得素材 → 鍊金 → 地下城生存」三者第一次串起來。
7. V0.1 優先驗證好不好玩，不追求內容量。
