# 1024 RPG — Type 02 Design Notes

## Status
**VERSION 1 · v0.1 INTEGRATED POC**

The previous City / Management direction (old v0.1–v0.3) is abandoned and archived. Type 02 is now a **three-board 1024 Roguelite**: 王國遠征、鍊金工坊、地下城探索都使用上下左右滑動與合併，但每個系統賦予 1024 不同意義。

> **1024 王國遠征 → 素材 → 1024 鍊金 → 回復藥 → 1024 地下城 → 素材 → 回城 → 再出發。**

---

# V0.1 POC — playable scope
V0.1 的目的不是完成完整遊戲，而是第一次把三種 1024 玩法串成一個可玩的循環。所有數值、配方、敵人與掉落都是 POC 暫定值。

## Town / 城鎮
城鎮是中央 Hub：⚔️ 王國遠征、🧪 鍊金工坊、🏰 地下城探索。城鎮庫存顯示 🦴一般素材、🔮Boss 核心、🧪回復藥與最佳地下城深度。

## Material system — V0.1 only
- **🦴 一般素材**：遠征普通敵人 / 地下城素材。
- **🔮 Boss 核心**：遠征 Boss 戰利品。
- V0.1 唯一鍊金成品：**🧪 回復藥**。

---

# 1. 王國遠征 — Expedition POC

## Core thesis
王國遠征的主要壓力是：**玩家在下方 1024 的合併 / 生兵速度，能否追上敵方自動產兵與前線推進速度。**

上半部是 2D 橫向自動戰場；下半部是 4×4 1024 單位鍛造盤。玩家不是直接攻擊，而是透過 Merge 持續補充遠征軍。

## Captain / 敗北條件
- 我方最左側固定存在一名 **隊長**，有獨立 HP 與血條。
- 隊長是遠征 Run 的核心生命線。
- 當玩家來不及生產士兵、敵軍突破前線後，敵軍會向左推進並攻擊隊長。
- **隊長 HP 歸零 = 本次遠征立即失敗。**
- 遠征失敗時，本次 Run 尚未安全帶回城的所有 🦴 / 🔮 戰利品全部失去；原本城鎮庫存不受影響。

## Merge → Unit
- 每發生 1 組真正 Merge，產生 1 名新士兵。
- 合併完成後的數字決定該士兵強度；數字越高，HP / 攻擊等能力越強。
- 同一次 Swipe 若完成多組 Merge，每組都各自產生一名士兵。
- **合併次數 = 兵量；合併階級 = 兵質。**
- 士兵從左側加入並自動向右前進。

## Unit variety / 戰場角色
V0.1 先驗證三種基本戰鬥角色：
- **近戰**：前線接敵、短距離攻擊。
- **弓箭手**：較遠距離攻擊，可選擇較後方目標，不一定只打最前面的敵人。
- **法師**：遠距離攻擊，可攻擊敵陣中段等不同位置。

敵軍也可包含近戰、弓手、法師。遠程敵人因此可能攻擊我方中間 / 後方士兵，而不是永遠只打最前線單位。

## Visible combat feedback
- 隊長、我方士兵、敵方小兵、Boss 全部有獨立 HP 與頭頂血條。
- 近戰碰撞後停止並攻擊；遠程單位在射程內即可攻擊。
- 攻擊有簡單可見動作；受擊時血條下降並有受擊回饋。
- HP 歸零播放簡單死亡動畫，再從戰場移除。
- 存活單位繼續前進。

## Three-stage V0.1 expedition
這一輪 POC 暫時實作 **3 個連續關卡 / 3 名 Boss**，每關主題、敵軍組成與強度不同：

1. **翠影林道** — 森林主題；較基礎的近戰敵軍，混入弓手；Boss：森牙王。
2. **赤砂峽谷** — 赤砂 / 火山主題；敵軍強度與生成速度提高，開始混合近戰、弓手、法師；Boss：赤角戰鬼。
3. **霜月要塞** — 冰霜要塞主題；敵軍更快、更強，遠程 / 法術壓力提高；Boss：霜月龍王。

後一關的小兵與 Boss 都比前一關更強，敵方生成節奏也更快。

## Boss checkpoint / Risk–Reward
- 每擊敗一名 Boss：本次 Run 暫存 **+1 🔮 Boss 核心**。
- Boss 擊敗後遊戲暫停並詢問：**帶戰利品回城 / 繼續下一關**。
- 選擇回城：本次遠征累積的所有 🦴 / 🔮 正式加入城鎮庫存。
- 選擇繼續：保留為「本次 Run 暫存戰利品」，進入更強的下一關；若之後隊長死亡，這些尚未帶回城的戰利品全部失去。
- 第三名 Boss 擊敗後，本次三關 POC 完成並安全帶回戰利品。
- 主動放棄遠征同樣不會帶回本次尚未結算的戰利品。

## POC question
> 玩家是否會因為敵軍持續生成，而產生「我必須更快、更有效率地合併 1024 才能守住隊長並推過前線」的操作壓力？Boss 後的回城 / 繼續是否能產生真正的風險報酬選擇？

# 2. 鍊金工坊 — Alchemy POC
鍊金工坊本身是一張 **4×4 1024 棋盤**，不是傳統 Craft 按鈕。

## V0.1 rules
- 玩家從城鎮庫存投入 🦴 與 🔮。
- 材料以 Tile 進入棋盤，透過上下左右 Swipe 整理與合併。
- 相同一般素材可合併升階。
- V0.1 測試配方：**2 × 🦴 + 1 × 🔮 → 1 × 🧪回復藥**。
- 製作必須透過 1024 棋盤完成，不改成一鍵 Craft。

## POC question
> 只有兩種材料時，透過 swipe 整理、合併與觸發配方，是否已經比傳統 Craft 選單有趣？

---

# 3. 地下城探索 — Dungeon POC
地下城是 **1024 Roguelike 棋盤**，棋盤本身就是探索空間。

## Core rule
- 玩家以 Swipe 改變棋盤局勢；一次有效滑動 = 一個探索 Turn。
- 棋盤可出現玩家、敵人、素材與下一層入口。
- 接觸敵人觸發戰鬥，接觸素材取得 🦴，接觸 ⬇️ 進入下一層。
- 深層逐步提高敵人強度。
- 玩家可使用 🧪 回復藥；V0.1 暫定 +5 HP。

## Infinite descent / death rule
地下城沒有固定最終層。玩家可主動回城安全帶回本次戰利品；死亡則失去本次地下城新取得素材，進地下城前的城鎮庫存不受影響。

## POC question
> 玩家是否會因為已取得的戰利品與剩餘 HP，在「再下一層」和「現在回城」之間產生真正的猶豫？

# V0.1 complete loop
**🏘️ TOWN**
→ ⚔️ 王國遠征
→ 1024 Merge 生兵 / 守護隊長 / 三關橫向自動戰鬥
→ Boss checkpoint 決定回城或冒險繼續
→ 安全回城才把 🦴 / 🔮 加入庫存
→ 🧪 1024 鍊金
→ 🧪 回復藥
→ 🏰 1024 地下城
→ 深入 / 使用藥水 / 收集素材
→ 主動回城或死亡
→ TOWN

---

# V0.1 deliberately excluded
為保持 POC 驗證優先，目前仍不做：大量兵種 / 職業、超過兩種素材、回復藥以外的大量鍊金道具、複雜配方圖鑑、地下城商人 / 祭壇 / 陷阱 / 鑰匙、完整永久 Meta progression、正式美術與複雜動畫。遠征目前只測三個關卡，不擴成完整世界地圖。

| --- | --- | --- | --- |
| 王國遠征 | 軍隊生產 | 每組 Merge 生產一名對應強度士兵 | 生兵速度 vs 敵軍速度、隊長生存、Boss checkpoint |

# Design principles
1. 玩家只需要熟悉上下左右 Swipe，但三種棋盤必須產生不同決策。
2. 1024 合併必須產生遊戲後果，不只是分數。
3. 王國遠征下方棋盤與上方戰場是一個系統：Merge 實際生產獨立士兵，玩家以合併效率抵抗敵軍生成壓力。
4. 遠征戰利品採 Run 暫存制；安全回城才正式入庫。
5. 鍊金必須透過 1024 棋盤完成。
6. 地下城必須透過 1024 Swipe 探索，並提供深入 / 撤退壓力。
7. V0.1 優先驗證好不好玩，不追求內容量。
