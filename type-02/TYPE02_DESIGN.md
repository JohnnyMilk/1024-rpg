# 1024 RPG — Type 02 Design Notes

## Status
**VERSION 1 · NEW CORE DIRECTION — DESIGN PHASE**

The previous City / Management direction (v0.1–v0.3) is abandoned after playtesting. Those builds remain archived only as design experiments.

Type 02 is now a **three-layer 1024 Roguelite**. The important correction is that 1024 is not only the unit-generation system: **王國遠征、鍊金工坊、地下城探索三個主要玩法都使用上下左右滑動與合併作為核心操作，但每一層對「合併」的解釋完全不同。**

> **1024 王國遠征 → 材料 → 1024 鍊金工坊 → 道具 → 1024 地下城探索 → 稀有材料 → 回家。**

---

## Core design thesis
玩家只需要學會一套主要操作：**上下左右滑動。**

但進入不同系統後，同樣的 1024 操作會產生不同策略：
- 遠征棋盤是在「組軍隊」；
- 鍊金棋盤是在「組配方」；
- 地下城棋盤是在「探索空間」。

因此遊戲保持手機操作簡單，深度則來自三種不同的棋盤規則與它們之間的資源循環。

---

## 1. 王國遠征 — 1024 Unit Forge + 2D Auto Battle
手機畫面分成上下兩層。

### 下方：4×4 1024 單位棋盤
- 玩家上下左右滑動。
- 單位在棋盤上移動、合併、升階。
- 合併結果直接產生或強化上方遠征隊。
- 不同階級可形成不同兵種、品質、技能或出場效果。
- 目標不是單純做出最大數字，而是根據上方戰況製造需要的部隊。

### 上方：平面 2D 橫向遠征
- 隊伍持續由左往右前進。
- 單位自動與怪物戰鬥。
- 下方每一次重要合併都立即反映到上方。
- 可遇到普通怪、精英、Boss、採集點、事件與寶箱。
- 戰鬥與探索取得鍊金材料。

**核心回饋：下面滑一下，上面就發生事情。**

---

## 2. 鍊金工坊 — 1024 Alchemy Board
鍊金不是傳統「點材料 → 按製作」介面，而是一個真正可玩的 1024 棋盤。

### 基本操作
- 進入工坊後，材料成為棋盤 Tile。
- 玩家仍然使用上下左右滑動。
- 相同材料可依 1024 邏輯合併升階，例如低階草藥 → 濃縮草藥 → 精華。
- 合併會騰出空間並產生更高階素材。

### 配方反應
鍊金不能只做「兩個一樣變成更大的同一材料」。棋盤還需要**異種材料反應**。

初步規則：
- 同類 + 同階：升階素材。
- 特定素材在一次滑動 / 合併後達成配方條件：觸發鍊金反應，轉化為成品。
- 成品本身也可以留在棋盤上繼續合併升階。

例：
- 🌿 草藥 + 🌿 草藥 → 🌿² 濃縮草藥
- 💎 魔晶 + 💎 魔晶 → 💎² 精煉魔晶
- 高階草藥 + 魔晶條件成立 → 🧪 回復藥
- 火素材 + 礦物素材條件成立 → 💣 炸彈

真正配方與反應規則待 POC 驗證，不在設計階段鎖死。

### 棋盤壓力
材料庫不是無限的。玩家必須決定：
- 哪些材料現在合掉；
- 哪些要保留等待配方；
- 哪些稀有材料不能浪費；
- 何時把完成品取出棋盤。

因此「整理鍊金桌」本身就是遊戲，而不是選單工作。

成品可包括藥水、炸彈、卷軸、陷阱、附魔、護符與特殊鑰匙。已發現的反應可記錄到鍊金圖鑑。

## 3. 地下城探索 — 1024 Dungeon Board
地下城也不是節點選單，而是第三種 1024 棋盤。

### 基本概念
**棋盤本身就是地下城。**

玩家每次上下左右滑動，不只是把數字推到一起，而是在改變隊伍與地下城物件的相對位置。一次有效滑動可視為一次探索 Turn。

棋盤可能包含：
- 🧙 玩家 / 隊伍；
- 👹 怪物；
- 🚪 門；
- 🧱 障礙；
- 💰 寶箱；
- ⚠️ 陷阱；
- 🔥 營火 / 祭壇；
- 🪨 可破壞地形；
- ⬇️ 下一層入口。

### 1024 式探索
- 滑動會改變棋盤局勢。
- 接觸敵人可觸發戰鬥或攻擊。
- 接觸寶箱取得戰利品。
- 特定道具可在棋盤上直接改變 Tile，例如炸掉牆、解除陷阱、治療、凍結敵人、打開特殊門。
- 怪物可在玩家有效滑動後行動，使每一步都有風險。
- 特殊 Tile 可以合併、升階或觸發事件，但地下城不必照搬標準 1024 的「同數字才合併」；探索性優先。

### 深入 / 撤退
玩家在地下城取得稀有素材後，要持續面對：
- 繼續往更深層走；
- 使用珍貴鍊金道具換取安全；
- 或帶著目前戰利品撤退。

地下城的 1024 核心不是追求 1024 這個數字，而是**用滑動管理空間、敵人、出口與有限道具。**

## Three-board identity
三個系統必須看起來是同一款遊戲，但玩起來不能只是換 Skin。

| 系統 | 1024 棋盤代表 | 合併的意義 | 主要壓力 |
| --- | --- | --- | --- |
| 王國遠征 | 軍隊生產 | 單位升階 / 出征 | 上方即時戰況 |
| 鍊金工坊 | 鍊金桌 | 素材升階 / 配方反應 | 空間、材料、配方 |
| 地下城 | 探索空間 | 戰鬥 / 地形 / 事件互動 | HP、敵人、路線、撤退 |

這是 Type 02 與 Type 01 最重要的差異之一：**不是在同一套戰鬥 1024 上加更多職業，而是讓同一個 swipe/merge 語言變成三種不同遊戲。**

---

## Primary roguelite loop

**HOME**
→ 選擇王國區域
→ **1024 UNIT FORGE + 2D EXPEDITION**
→ 獲得材料
→ **1024 ALCHEMY BOARD**
→ 製作有限道具
→ 選擇裝備 / 攜帶品
→ **1024 DUNGEON BOARD**
→ 戰鬥 / 探索 / 使用鍊金道具
→ 取得稀有材料
→ 撤退或繼續深入
→ HOME
→ 下一輪
→ run 結束
→ roguelite 永久解鎖

---

## World map
大地圖負責選擇資源方向，而不是傳統 RTS 佔領。

可能區域：
- 森林：草藥、木材、野獸素材；
- 礦山：礦石、金屬、魔晶；
- 沼澤：毒素、菌類、異變素材；
- 遺跡：卷軸、古代零件、魔法核心；
- 地下城入口：高風險、高稀有度資源。

玩家會因為「想做什麼鍊金道具」反過來決定下一次去哪裡遠征。

---

## Roguelite persistence
永久進度初步以解鎖選擇為主：
- 新鍊金配方；
- 新兵種；
- 新素材；
- 新遠征區域；
- 新地下城 / Boss；
- 少量工坊功能。

避免主要依賴永久數值膨脹。

---

## Development order / POCs
雖然最終三層都使用 1024，但仍然分階段驗證。

### POC A — Expedition
只做：
**下方 4×4 swipe/merge → 產生 / 強化上方單位 → 2D 自動打怪 → 掉材料。**

### POC B — Alchemy
只做：
**材料進入 4×4 → swipe/merge 升階 → 異種材料觸發配方 → 取出成品。**

### POC C — Dungeon
只做：
**4×4 / 可變尺寸地下城 → swipe 探索 → 敵人回合 → 寶箱 / 障礙 / 出口 → 使用 1–2 種鍊金道具。**

三個 POC 各自證明好玩後，再串成完整 roguelite run。

## Design principles
1. 玩家只需要熟悉 swipe，但三種棋盤必須產生三種不同決策。
2. 1024 合併必須產生遊戲後果，不只是分數。
3. 遠征的下方棋盤與上方動畫是一個系統。
4. 鍊金必須「真的玩 1024」，不是把 1024 當裝飾介面。
5. 地下城必須「真的用 swipe 探索」，不是節點選單套 1024 外觀。
6. 道具必須能改變地下城棋盤局勢。
7. 三個系統透過材料 / 道具形成閉環。
8. Meta progression 優先解鎖可能性，而不是永久堆數值。
9. 每一個 POC 先證明核心好玩，再投資 UI 與動畫。
