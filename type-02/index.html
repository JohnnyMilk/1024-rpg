CURRENT · DESIGN PHASE
下方製造部隊，上方遠征世界

手機下半部維持上下左右滑動的 4×4 1024 棋盤。每次合併直接產生或強化上半部的遠征單位；隊伍以平面 2D 從左向右前進，自動與怪物戰鬥並取得鍊金材料。

材料帶回工坊後可自由實驗配方，製作藥水、炸彈、卷軸、附魔與特殊用品。完成準備後進入分支地下城，在風險與戰利品之間決定繼續深入或撤退。
